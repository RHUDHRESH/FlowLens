# Evaluation protocol

## Data

All data is generated by the deterministic simulator in this repository. Split by scenario family and seed (`flowlens/diagnosis/splits.py`). Windows from one journey stay in one split. The withheld mechanism `mechanical_resistance` is excluded from fitting and calibration.

## Metrics (required language)

Always distinguish:

- **Achieved simulated result** — what `python -m flowlens verify` / `benchmark` printed.
- **Target** — a development goal, not a claim.
- **Assumption** — e.g. public graph priors.
- **Proposed future field validation** — not done.

Never describe simulator performance as elevator field performance.

## Baselines in this tag

Smoke comparison in `benchmarks/run_benchmark.py`:

- Alarm-code lookup (first mapped alarm).
- Static hand rule DAG (missing LOCK_PROVED → door lock, etc.).
- FlowLens envelope decision / top label.

Full boosted-classifier and complete ablation suite are **not** claimed in this screening tag.

## Reproduction

```
python -m flowlens verify --seed 20260915
python -m flowlens benchmark
python -m pytest -q
```
